# Lá de Casa Bolos Caseiros

Site institucional. React + Vite + Tailwind CSS.

## Publicar na Vercel
- **Sem GitHub:** arraste o `ladecasa-site-pronto.zip` em vercel.com/drop.
- **Com GitHub:** envie esta pasta para um repositório e importe na Vercel (Add New → Project).

## Fotos
As fotos dos bolos estão em `public/fotos/bolos` (recortadas do iFood da loja).
Para fotos de ambiente (abertura, loja, galeria), coloque os arquivos em `public/fotos` e preencha `FOTOS` em `src/LaDeCasaSite.jsx`.
